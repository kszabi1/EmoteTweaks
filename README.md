# EmoteTweaks
 
A mod that plays sounds with emotes with the help of [Simple Voice Chat](https://modrepo.de/minecraft/voicechat/overview).
 
## About this fork
 
This is a maintenance fork of [ZigyTheBird/EmoteTweaks](https://github.com/ZigyTheBird/EmoteTweaks), which is itself a
fork of [wolf-mc-mods/EmoteTweaks](https://github.com/wolf-mc-mods/EmoteTweaks), originally created by
[RyanV](https://github.com/BounceSMP/EmoteTweaks).
 
ZigyTheBird's version hasn't seen an update in over a year, so I picked it up to keep it working on current versions
and fix outstanding issues. **This is not an attempt to take over the project or fragment it further** — if
ZigyTheBird (or anyone upstream) resumes active development, I'll gladly upstream my changes back into their repo via
PR and stop maintaining this fork separately, rather than keep it going as a competing branch.
 
If you're looking for the original, check the links above first — this fork exists purely to fill the gap while it's
inactive.
